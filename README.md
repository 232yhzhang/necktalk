# NeckTalk · 颈边实时双语字幕

一个纯前端的实时中英互译字幕网页。打开摄像头与麦克风后，NeckTalk 会识别说话人的语音，自动翻译成另一种语言，把「原文 + 译文」的双语字幕贴在说话人的颈部附近，并标注「发言人A / 发言人B」。

在线体验：<https://232yhzhang.github.io/necktalk/>

## 功能

- 中文 / English 实时语音识别，识别中的原文会先以半透明形式出现
- 中文说话时自动显示英文翻译；英文说话时自动显示中文翻译
- 多维发言人标注「发言人A / 发言人B / …」，每位发言人使用不同颜色
- 人脸与颈部追踪，双语字幕气泡跟随正在说话的人移动
- 字幕记录面板：原文与译文同时保存，可复制全文、导出双语 SRT、清空记录
- 优先使用浏览器内置翻译；否则通过 Mozhi 社区实例调用 DeepL，失败时回退到 MyMemory
- 画面镜像开关；镜像只影响画面，不影响字幕阅读
- 人脸追踪模型、WASM 均为本站静态资源；响应式适配桌面与手机竖屏

## 使用方式

1. 使用最新版桌面 Chrome 或 Edge 打开网页（这两种浏览器对页面内语音识别支持最完整）。
2. 在右上角「说话语言」选择你将要说的话：`中文` 或 `EN`。字幕会自动翻译成另一种语言。
3. 点击「开启摄像头 · 开始翻译」，允许摄像头与麦克风权限。
4. 让说话人的脸部出现在画面中并开始说话。双语字幕会出现在其下巴下方的颈部位置。
5. 右上角或底部「记录」可查看完整双语字幕，并复制或导出 SRT。
6. 「结束翻译」停止本次会话；记录会保留，重新开始新会话会清空当前记录。

语言切换适用于「下一位说话人换了一种语言」的场景。由于浏览器语音识别的限制，一次只会运行一种识别语言，切换语言会重启识别。

## 实现方式

- **语音识别**：浏览器原生 Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`），开启 `continuous` 与 `interimResults`，通过自动重启保持在听状态。
- **实时翻译**：`assets/translate.js` 提供翻译队列与缓存。若浏览器支持内置 `Translator` API 且语言包已就绪，优先使用本地内置翻译；否则通过 Mozhi 社区实例调用 DeepL（译文更自然），DeepL 不可用时自动回退到 MyMemory 免费翻译 API。每条字幕会在更新后自动排队翻译，并限制并发与请求频率。
- **面部与颈部定位**：MediaPipe Face Landmarker 在本地对视频逐帧检测，取得下巴、额头等关键点，在颈部高度生成字幕锚点。模型与 WASM 位于 `assets/vendor/`，不上传画面。
- **发言人判断**：同时读取每个面部的 `jawOpen` 值，并与麦克风音量包络做短时相关性计算；结合嘴部动作能量推断当前说话人，再为字幕分配「发言人」编号。字幕气泡按照面部轨迹平滑移动。
- **双语显示**：同一字幕气泡内分为原文行与译文行；原文实时显示识别中的草稿，译文在断句后更新。字幕记录面板保存完整双语文本，SRT 每个 cue 同时包含原文与译文。
- **稳定性处理**：识别空闲自动重启；语言切换即时重启；识别服务异常可自动重试；翻译失败时保留原文并提示；人脸追踪不可用时字幕自动回退到画面底部。

## 已知限制

- 浏览器语音识别通常依赖厂商的在线服务，需要联网。Chrome 使用 Google 的语音服务，Edge 使用 Microsoft 的服务。网络无法访问相应服务时，会显示「连接重试中」。
- 在线翻译需要联网。默认经 Mozhi 社区实例调用 DeepL；该实例是公开服务，可能限流或不可用，此时会回退到 MyMemory，译文自然度可能下降。单次请求限制为 470 字符。所有在线翻译服务都不可用时，页面会只显示原文。
- 翻译在断句后开始请求，在线翻译通常需要约 1–2 秒返回；它不是逐词同传，连续说话时译文会随后更新。
- 一次只能运行一种识别语言；中英文混说或不同发言人使用不同语言时，需要手动切换「说话语言」。
- 发言人归属是**基于嘴唇动作与音量相关性的启发式判断，不是声纹识别**。多人同时说话、背对镜头、脸部被遮挡或光线过暗时可能误判或串位。建议一次一人发言、保持正脸入镜。
- 人脸追踪模型约 20 MB，首次点击开始时需要下载，之后由浏览器缓存。
- Firefox 不支持 Web Speech 识别；Safari / iOS 的支持程度取决于系统版本，建议使用桌面版 Chrome / Edge。

## 隐私

- 摄像头画面只在本地浏览器中用于人脸追踪，不上传服务器。
- 语音识别由浏览器自带的语音服务完成，音频是否上传取决于所用的浏览器与厂商实现（Chrome / Edge 通常会发送到在线语音服务）。
- 识别出的文字会发送给 DeepL（经由 Mozhi 公共实例）；若不可用则发送给 MyMemory。如果浏览器内置翻译可用，则优先在本地完成翻译。这些服务有其自己的隐私政策与保留规则。
- 字幕记录仅保存在当前页面内，刷新或关闭页面即丢失；导出文件也只在本地生成。

## 本地运行

本项目是静态站点，不需要构建：

```powershell
cd necktalk
python -m http.server 4173
```

然后打开 <http://localhost:4173>。请勿直接双击 `index.html` 使用 `file://` 协议，浏览器会阻止摄像头、麦克风与模块加载。

也可以使用任意静态服务器，例如 `npx serve .`。

## 部署

站点通过 GitHub Pages 从 `main` 分支根目录发布，不需要构建命令；推送新的 `main` 提交后会自动重新部署。

## 目录

```text
index.html                  页面结构
assets/styles.css           界面样式
assets/app.js               会话、双语字幕、翻译队列、面板与发言人逻辑
assets/face-tracker.js      MediaPipe 人脸 / 颈部追踪封装
assets/recognition.js       Web Speech 识别控制器
assets/translate.js         翻译服务：浏览器 Translator + MyMemory 回退
assets/vendor/              MediaPipe Tasks Vision、WASM 与 Face Landmarker 模型
```
